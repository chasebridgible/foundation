## Scout interpretation

This is a meaningful 7/10 evaluation pattern for agent systems: capability claims for modernization work should test observable behavior across the relevant execution environment, rather than equating a compiling rewrite or a fluent explanation with safe preservation. It does not establish a new standalone Foundation principle because the current evaluation doctrine already requires environment-grounded, replayable evaluation, regression coverage, and whole-system evidence.
