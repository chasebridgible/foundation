## New in scoped material since the 2026-10-20 checkpoint

Anthropic published **Donating Agent Skills to the Agentic AI Foundation** on October 22, 2026. It describes Agent Skills as a vendor-neutral folder convention centered on `SKILL.md`, procedures, scripts, and references, and announces that the standard, name, GitHub organization, and domain are moving to the Agentic AI Foundation under the Linux Foundation. The post says more than 70 platforms have integrated the convention.

Source: https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation

## Scout interpretation

This is a 7/10 ecosystem finding: portable, procedure-shaped skill packages are becoming a cross-platform context and workflow interface rather than an implementation-specific convention. It does not create a standalone Foundation principle candidate: the existing Agent Principles already define skills as reusable workflow packages and require stable, inspectable artifacts, while Foundation's existing skills already implement that operating model.
